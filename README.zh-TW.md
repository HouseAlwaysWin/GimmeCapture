# GimmeCapture!!

一套把截圖、錄影、翻譯與釘選視窗整合在一起的 Windows 桌面工具。

## 專案介紹

**GimmeCapture!!** 是使用 **Avalonia** 開發的 Windows 桌面擷取工具，整合了快速截圖、螢幕錄影、OCR 輔助翻譯、浮動釘選視窗與基本標註功能。

專案名稱靈感來自 **BABYMETAL** 的 **["Gimme chocolate!!"](https://www.youtube.com/watch?v=WIKqgE4BwAY)**，整體視覺風格也延續了這種強烈、高對比的設計方向。

## 主要功能

- **截圖模式**：快速框選畫面，之後可複製、儲存、標註或釘選
- **錄影模式**：支援桌面錄影、系統音訊與即時工具列控制
- **翻譯模式**：提供 OCR 輔助選取與本地翻譯結果覆蓋框
- **釘選視窗**：圖片與影片都可釘在最上層作為參考
- **標註工具**：可直接繪製方框、箭頭、直線與文字
- **自訂快捷鍵**：可在 Control 頁籤中調整各種操作熱鍵
- **外觀調整**：可調整主題色、邊框粗細、遮罩透明度與裝飾顯示

## 翻譯模式

翻譯模式主要面向桌面 UI、文件、漫畫與一般畫面文字的 OCR 翻譯流程。

- 可手動建立一個或多個翻譯框
- 也可透過 OCR 輔助框快速點選文字區塊
- OCR 輔助框會在按住設定的選取修飾鍵時出現
- 翻譯結果會以可移動、可調整大小的覆蓋框顯示
- OCR 原文顯示可另外切換查看
- 翻譯走 **LlamaSharp (GGUF)** 本地模型

### 目前保留的本地翻譯模型

目前使用者可見的翻譯模型清單為：

- **TranslateGemma 4B**：主要推薦模型
- **Gemma 3 4B**：穩定的通用備用模型

## AI 模組下載

AI 資源會透過 **Modules** 頁籤按需下載。

目前模組分類包含：

- **ONNX Runtime & U2Net**：去背執行環境與模型
- **SAM2 Model**：智慧物件 / 區域選取
- **PaddleOCR v5**：OCR 偵測與辨識
- **Llama Models**：本地 GGUF 翻譯模型

## 釘選視窗

釘選視窗適合在工作時保留參考內容。

- 可將截圖釘選成浮動圖片視窗
- 可將錄影片段釘選成浮動影片視窗
- 維持置頂，同時保留輕量互動

## 錄影功能

錄影模式支援：

- 螢幕錄影與系統 / 桌面音訊
- MP4、MKV、GIF、WebM、MOV 等輸出格式
- 即時錄影工具列控制
- 錄影時音量狀態顯示

## 補充說明

- 專案仍在持續調整中，尤其是翻譯與 AI 相關流程會隨版本持續優化。
- 可選 AI 資源請以 **Modules** 頁籤中的下載與狀態為準。

## 第三方元件

- **FFmpeg / FFmpeg.AutoGen**：媒體錄製、播放、探測與處理
- **NAudio**：系統音訊擷取與監控
- **ONNX Runtime**：本地 AI 推論執行環境
- **PaddleOCR**：OCR 流程
- **LlamaSharp**：本地 GGUF 翻譯推論
