# GimmeCapture!!

一款集截圖、錄影、翻譯與釘選於一身，讓你的螢幕操作充滿風格的工具。

## 總覽

**GimmeCapture!!** 是一款以 **Avalonia** 搭配 **.NET 10** 打造的跨平台桌面擷取工具，可在 **Windows** 與 **Linux (X11)** 上執行。它將快速截圖、螢幕錄影、OCR 輔助翻譯、浮動釘選視窗、行程內影片壓縮，以及本機 AI 工具（OCR、背景移除、智慧選取、翻譯）全部整合於單一應用程式中。

專案名稱是向 **BABYMETAL** 及歌曲 **["Gimme chocolate!!"](https://www.youtube.com/watch?v=WIKqgE4BwAY)** 致敬，視覺風格也延續了同樣大膽、高對比的能量。

## 特色亮點

- **截圖模式**：快速擷取一塊區域，接著即可複製、儲存、標註或釘選。
- **錄影模式**：錄製你的螢幕，可混入系統與麥克風音訊、加入子母畫面攝影機、按鍵浮層，並提供即時工具列控制。
- **捲動擷取**：一邊捲動，一邊將長網頁或聊天內容拼接成一張長圖。
- **翻譯模式**：以 OCR 輔助選取區域，並以本機翻譯覆蓋顯示結果。
- **壓縮頁籤**：將任何影片重新編碼縮小（H.264/H.265），支援批次佇列與進階編輯器。
- **釘選視窗**：將圖片與影片保持在最上層，化為浮動的參考視窗。
- **AI 工具**：背景移除、智慧物件／區域選取，以及 OCR——全部在本機執行，並依需求下載。
- **標註工具**：方框、箭頭、線條、文字、馬賽克／模糊遮蔽、螢光筆、對話框與步驟標記。
- **自訂快速鍵**與**視覺自訂**（主題色彩、邊框粗細、遮罩不透明度、裝飾樣式）。
- **應用程式內自動更新**：無須離開應用程式即可下載並安裝新版本。

## 平台支援

GimmeCapture 可在 **Windows 10/11** 與 **Linux (X11)** 上執行。

- **Windows**——完整功能集，包含**逐視窗 GPU 擷取**（Windows Graphics Capture）、原生系統匣，以及選用的安裝程式。
- **Linux (X11)**——於 **Linux Mint**（以 Ubuntu 為基礎）上開發並**測試**。截圖／擷取、錄影（螢幕透過 x11grab + **系統／麥克風音訊透過 PulseAudio** + **子母畫面攝影機透過 V4L2**）、翻譯、釘選播放、壓縮、捲動擷取，以及應用程式內自動更新皆可運作。**逐視窗 (WGC) 錄影在 Linux 上沒有對應機制，因此會隱藏**——擷取範圍選擇器仍保留顯示器選項。全域快速鍵使用 X11（在 XWayland 下可運作；原生 Wayland 全域快速鍵尚未支援）。

## 錄影

錄影模式支援：

- 螢幕錄影，可搭配桌面／系統音訊與選用的**麥克風**混音
- **子母畫面攝影機**（可設定角落位置、大小，以及矩形／圓形外觀）
- **按鍵浮層**與游標／點擊視覺化
- 多種匯出格式：**MP4、MKV、GIF、WebM、MOV**（以調色盤為基礎的高品質 GIF）
- **擷取範圍選擇器**——錄製特定顯示器（兩個平台皆可）或視窗（Windows/WGC）
- 即時錄影工具列、音量回饋、靜音切換，以及全域停止快速鍵

## 捲動擷取

擷取比螢幕更高的內容——例如長網頁、文件或聊天記錄：

- 選取一塊區域，接著親手捲動目標，過程中會擷取並拼接各個畫格
- 自動偵測垂直／水平方向（或鎖定某個方向）
- 擷取區域的外框不會出現在拼接後的影像中，並會將你的捲動操作傳遞至目標

## 翻譯模式

翻譯模式專為桌面 UI、文件、漫畫與截圖上的快速「OCR 轉翻譯」工作流程而設計。

- 可手動選取一個或多個區域，或使用 OCR 輔助的快速選取。
- 按住設定的選取輔助鍵時，會出現 OCR 小工具。
- 翻譯結果會保留為可移動、可調整大小的覆蓋方框。
- OCR／原文可分別切換顯示以便檢視。
- 翻譯透過 **LlamaSharp (GGUF)** 在本機執行。

### 精選本機翻譯模型

目前提供給使用者的本機翻譯模型清單如下：

- **TranslateGemma 4B**：主要推薦模型
- **Gemma 3 4B**：穩定的通用備援模型

## 壓縮

匯入任何影片，並完全在行程內（libav）將其重新編碼縮小：

- **H.264 / H.265**、**壓縮至目標大小**（H.264 採用真正的雙通道）、解析度縮小、影格率上限、編碼器預設、CRF，以及音訊位元率／單聲道-立體聲混音或移除音訊。
- **批次佇列**，支援平行編碼、逐項設定與預設集，並提供即時的輸出大小估算。
- **進階影片編輯器**：修剪／變速／裁切／旋轉，加上標註、遮蔽與定格畫面，並提供內嵌的並排品質比較。

## AI 模組

AI 資源會從 **Modules** 頁籤依需求下載。

目前的模組群組包括：

- **ONNX Runtime 與 U2Net**：背景移除的執行環境與模型
- **SAM2 Model**：智慧物件／區域選取
- **PaddleOCR v5**：OCR 偵測與辨識
- **Llama Models**：本機 GGUF 翻譯模型

## 釘選視窗

釘選視窗適合在工作時快速參考之用。

- 將擷取的圖片釘選為浮動視窗
- 釘選影片片段並附帶播放控制（含音訊）
- 在保持輕量互動的同時，讓視窗維持在最上層

## 更新

- 應用程式會檢查是否有新版本，並可**就地下載並安裝更新**，接著重新啟動。
- 在 Windows 上，更新為可攜式 `.zip`；在 Linux 上則為自足式的單一檔案 `.tar.gz`。
- 下載內容會先對照發行版的 `SHA256SUMS.txt` 進行驗證，通過後才會套用。

## 附註

- 本專案正持續積極迭代，因此翻譯與 AI 工作流程可能會隨版本演進而變化。
- Modules 頁籤是安裝或更新選用 AI 資源的預期位置。

## 第三方元件

- **FFmpeg / FFmpeg.AutoGen**：媒體錄製、播放、探測與處理（x11grab / PulseAudio / V4L2 / dshow / gdigrab）
- **NAudio**：Windows 上的系統音訊擷取（WASAPI）
- **ONNX Runtime**：本機 AI 推論執行環境
- **PaddleOCR**：OCR 流程
- **LlamaSharp**：用於翻譯的本機 GGUF 推論
- **SkiaSharp**：影像處理、標註與合成

## 系統需求

- **Windows 10 / Windows 11**（x64），或
- **Linux (x86-64)**，須具備 **X11 工作階段**與 **PulseAudio**。於 **Linux Mint** 上開發並**測試**；可在以現代 glibc 為基礎的 Ubuntu/Debian 系列發行版上執行（例如 **Ubuntu 22.04+** 或 **Debian 12+**）。在 Wayland 桌面環境下，會透過 **XWayland** 執行。並非為 musl/Alpine 或 ARM 建置。

Linux 版本以自足式的單一檔案 `.tar.gz` 形式發布（無須安裝 .NET），並隨附 FFmpeg 的 `.so` 函式庫；Windows 版本則以可攜式 `.zip` 及選用的安裝程式形式發布。
