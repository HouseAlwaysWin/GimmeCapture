# Release Catalog

This folder keeps a structured release catalog for GimmeCapture starting from `v0.1.0`.

Files:

- `releases.md`: timeline-style catalog of released versions, dates, and major changes.

Maintenance notes:

- Add a new section to `releases.md` whenever a new version tag is created.
- Keep entries high-signal and user-facing; avoid dumping every internal commit.
- Use `CHANGELOG.md` for broader notes and `docs/catalog/releases.md` as the canonical release timeline.
