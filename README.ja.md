# GimmeCapture!!

スニップ、録画、翻訳、ピン留めを、スタイリッシュに一つでこなすツール。

## 概要

**GimmeCapture!!** は、**Avalonia** と **.NET 10** で構築されたクロスプラットフォームのデスクトップキャプチャツールで、**Windows** と **Linux (X11)** の両方で動作します。素早いスニップ、画面録画、OCR を活用した翻訳、フローティングピンウィンドウ、プロセス内での動画圧縮、そしてローカル AI ツール（OCR、背景除去、スマート選択、翻訳）を、すべて一つのアプリにまとめています。

プロジェクト名は **BABYMETAL** と楽曲 **["Gimme chocolate!!"](https://www.youtube.com/watch?v=WIKqgE4BwAY)** へのオマージュです。ビジュアルスタイルも、あの大胆でハイコントラストなエネルギーを踏襲しています。

## 主な特徴

- **スニップモード**: 領域を素早くキャプチャし、コピー、保存、注釈、ピン留めができます。
- **録画モード**: システム音声とマイク音声、ウェブカメラのピクチャーインピクチャー、キーストロークオーバーレイ、リアルタイムのツールバー操作とともに画面を録画します。
- **スクロールキャプチャ**: スクロールしながら、長いページやチャットを縦長の一枚の画像につなぎ合わせます。
- **翻訳モード**: OCR を活用した領域選択と、ローカルでの翻訳オーバーレイ。
- **圧縮タブ**: あらゆる動画をより小さく再エンコード（H.264/H.265）。バッチキューと高度なエディターを備えています。
- **ピンウィンドウ**: 画像や動画を最前面のフローティング参照ウィンドウとして表示し続けます。
- **AI ツール**: 背景除去、スマートなオブジェクト／領域選択、OCR — すべてローカルで動作し、必要に応じてダウンロードされます。
- **注釈ツール**: ボックス、矢印、直線、テキスト、モザイク／ぼかしによる伏せ字、ハイライター、吹き出し、ステップマーカー。
- **カスタムホットキー** と **ビジュアルカスタマイズ**（テーマカラー、枠線の太さ、マスクの不透明度、装飾）。
- **アプリ内自動アップデート**: アプリを離れることなく、新しいリリースをダウンロードしてインストールします。

## プラットフォーム対応

GimmeCapture は **Windows 10/11** と **Linux (X11)** で動作します。

- **Windows** — **ウィンドウ単位の GPU キャプチャ**（Windows Graphics Capture）、ネイティブのシステムトレイ、オプションのインストーラーを含む、フル機能セット。
- **Linux (X11)** — **Linux Mint**（Ubuntu ベース）で開発・**テスト**されています。スニップ／キャプチャ、録画（x11grab による画面録画 ＋ **PulseAudio によるシステム／マイク音声** ＋ **V4L2 によるウェブカメラ PiP**）、翻訳、ピン再生、圧縮、スクロールキャプチャ、アプリ内自動アップデートはすべて動作します。**ウィンドウ単位（WGC）の録画は Linux に相当機能がないため非表示**になっています — キャプチャ範囲の選択ではモニター選択が引き続き利用できます。グローバルホットキーは X11 を使用します（XWayland 上では動作しますが、ネイティブ Wayland のグローバルホットキーはまだサポートされていません）。

## 録画

録画モードは以下をサポートします:

- デスクトップ／システム音声と、オプションの **マイク** ミキシングを伴う画面録画
- **ウェブカメラのピクチャーインピクチャー**（表示位置、サイズ、矩形／円形の形状）
- **キーストロークオーバーレイ** とカーソル／クリックの可視化
- 複数のエクスポート形式: **MP4、MKV、GIF、WebM、MOV**（高品質なパレットベースの GIF）
- **キャプチャ範囲の選択** — 特定のモニター（両プラットフォーム）またはウィンドウ（Windows/WGC）を録画
- リアルタイムの録画ツールバー、音量レベルのフィードバック、ミュート切り替え、グローバルな停止ホットキー

## スクロールキャプチャ

長いウェブページ、ドキュメント、チャットログなど、画面より縦に長いコンテンツをキャプチャします:

- 領域を選択し、フレームがキャプチャ・つなぎ合わされる間、対象を手動でスクロールします
- 縦／横方向の自動判定（または方向の固定）
- キャプチャ領域の枠線はつなぎ合わされた画像に含まれず、スクロール操作はそのまま対象へ伝わります

## 翻訳モード

翻訳モードは、デスクトップ UI、ドキュメント、漫画、スクリーンショットにおける、OCR から翻訳までの高速なワークフローのために設計されています。

- 一つまたは複数の領域を手動で選択するか、OCR を活用したクイック選択を使用します。
- 設定した選択用の修飾キーを押している間、OCR ヘルパーが表示されます。
- 翻訳結果は、移動可能・リサイズ可能なオーバーレイボックスとして残ります。
- OCR ／原文テキストは、確認のために個別に表示を切り替えられます。
- 翻訳は **LlamaSharp (GGUF)** を通じてローカルで実行されます。

### 厳選されたローカル翻訳モデル

現在ユーザー向けに提供されているローカル翻訳モデルは以下のとおりです:

- **TranslateGemma 4B**: 推奨される主要モデル
- **Gemma 3 4B**: 安定した汎用フォールバック

## 圧縮

あらゆる動画を取り込み、すべてプロセス内（libav）でより小さく再エンコードします:

- **H.264 / H.265**、**目標サイズへの圧縮**（H.264 では真の 2 パス）、解像度のダウンスケール、フレームレートの上限設定、エンコーダープリセット、CRF、音声ビットレート／モノ・ステレオのミックスダウンまたは音声の除去。
- **バッチキュー**（並列エンコード対応）、項目ごとの設定＋プリセット、出力サイズのリアルタイム推定。
- **高度な動画エディター**: トリミング／速度変更／クロップ／回転に加え、注釈、伏せ字、フリーズフレーム、そしてインラインでの並列品質比較。

## AI モジュール

AI リソースは **モジュール** タブから必要に応じてダウンロードされます。

現在のモジュールグループには以下が含まれます:

- **ONNX Runtime & U2Net**: 背景除去のランタイムとモデル
- **SAM2 Model**: スマートなオブジェクト／領域選択
- **PaddleOCR v5**: OCR の検出と認識
- **Llama Models**: ローカルの GGUF 翻訳モデル

## ピンウィンドウ

ピン留めしたウィンドウは、作業中に素早く参照するためのものです。

- キャプチャした画像をフローティングウィンドウとしてピン留め
- 再生コントロール付きで動画クリップをピン留め（音声も含む）
- 軽快な操作性を保ちながらウィンドウを最前面に維持

## アップデート

- アプリは新しいリリースを確認し、**その場でアップデートをダウンロードしてインストール**した後、再起動できます。
- Windows ではアップデートはポータブルな `.zip`、Linux では自己完結型の単一ファイル `.tar.gz` です。
- ダウンロードは適用前に、リリースの `SHA256SUMS.txt` と照合して検証されます。

## 備考

- 本プロジェクトは活発に改良が続けられているため、翻訳や AI のワークフローはリリースごとに変化する可能性があります。
- オプションの AI リソースをインストールまたは更新する場所として、モジュールタブが想定されています。

## サードパーティコンポーネント

- **FFmpeg / FFmpeg.AutoGen**: メディアの録画、再生、プロービング、処理（x11grab / PulseAudio / V4L2 / dshow / gdigrab）
- **NAudio**: Windows でのシステム音声キャプチャ（WASAPI）
- **ONNX Runtime**: ローカル AI 推論ランタイム
- **PaddleOCR**: OCR パイプライン
- **LlamaSharp**: 翻訳のためのローカル GGUF 推論
- **SkiaSharp**: イメージング、注釈、合成

## 動作要件

- **Windows 10 / Windows 11**（x64）、または
- **X11 セッション** と **PulseAudio** を備えた **Linux (x86-64)**。**Linux Mint** で開発・**テスト**されており、モダンな glibc ベースの Ubuntu/Debian 系ディストリビューション（例: **Ubuntu 22.04+** や **Debian 12+**）で動作します。Wayland デスクトップでは **XWayland** 上で動作します。musl/Alpine や ARM 向けにはビルドされていません。

Linux 版は、FFmpeg の `.so` ライブラリを同梱した自己完結型の単一ファイル `.tar.gz`（.NET のインストール不要）として提供されます。Windows 版は、ポータブルな `.zip` とオプションのインストーラーとして提供されます。
