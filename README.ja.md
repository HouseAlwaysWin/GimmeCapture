## 概要

**GimmeCapture!!** は **Avalonia** で構築された Windows 向けのキャプチャツールです。高速なスクリーンショット、画面録画、OCR 補助付き翻訳、フローティングのピン留めウィンドウ、基本的な注釈機能を 1 つのアプリにまとめています。

プロジェクト名は **BABYMETAL** の **["Gimme chocolate!!"](https://www.youtube.com/watch?v=WIKqgE4BwAY)** へのオマージュです。UI もその雰囲気に合わせた、強めのコントラストと存在感のあるデザインになっています。

## 主な機能

- **Snip モード**: 素早く範囲を切り取り、コピー、保存、注釈、ピン留めが可能
- **Record モード**: 画面録画、システム音声、リアルタイムのツールバー操作に対応
- **Translate モード**: OCR 補助選択とローカル翻訳オーバーレイを提供
- **ピン留めウィンドウ**: 画像や動画を常に前面に保持
- **注釈ツール**: 四角形、矢印、直線、テキストを追加可能
- **ホットキーのカスタマイズ**: Control タブから各種ショートカットを変更可能
- **見た目の調整**: テーマカラー、枠線の太さ、マスク透明度、装飾表示を調整可能

## Translate モード

Translate モードは、デスクトップ UI、ドキュメント、コミック、各種スクリーンショット上の文字を OCR 経由で翻訳するためのワークフローです。

- 手動で 1 つ以上の翻訳ボックスを作成可能
- OCR 補助候補をクリックして素早く選択可能
- OCR 補助候補は、設定された選択モディファイアを押している間だけ表示
- 翻訳結果は移動・リサイズ可能なオーバーレイボックスとして表示
- OCR 原文表示は別途切り替え可能
- 翻訳は **LlamaSharp (GGUF)** のローカルモデルで実行

### 現在のローカル翻訳モデル

現在ユーザー向けに表示している翻訳モデルは次の 2 つです。

- **TranslateGemma 4B**: 主推奨モデル
- **Gemma 3 4B**: 安定した汎用フォールバック

## AI モジュール

AI リソースは **Modules** タブから必要に応じてダウンロードします。

現在のモジュール分類:

- **ONNX Runtime & U2Net**: 背景除去ランタイムとモデル
- **SAM2 Model**: スマートなオブジェクト / 領域選択
- **PaddleOCR v5**: OCR の検出と認識
- **Llama Models**: ローカル GGUF 翻訳モデル

## ピン留めウィンドウ

ピン留めウィンドウは作業中の参照用として使えます。

- キャプチャ画像をフローティング画像ウィンドウとして保持
- 録画クリップをフローティング動画ウィンドウとして保持
- 常に前面に表示しつつ、軽量な操作性を維持

## 録画機能

Record モードでは以下をサポートします。

- 画面録画とシステム / デスクトップ音声
- MP4、MKV、GIF、WebM、MOV などの出力形式
- リアルタイム録画ツールバー操作
- 録画中の音量状態表示

## 補足

- 本プロジェクトは継続的に改善中であり、特に翻訳と AI 関連の挙動はリリースごとに調整される可能性があります。
- 利用可能な AI リソースは **Modules** タブの状態表示を基準にしてください。

## サードパーティコンポーネント

- **FFmpeg / FFmpeg.AutoGen**: 録画、再生、解析、メディア処理
- **NAudio**: システム音声の取得と監視
- **ONNX Runtime**: ローカル AI 推論ランタイム
- **PaddleOCR**: OCR パイプライン
- **LlamaSharp**: ローカル GGUF 翻訳推論

## 動作環境

- Windows 10 / Windows 11
