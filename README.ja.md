# GimmeCapture!! 🦊 (Japanese)

スタイリッシュで高性能なスクリーンキャプチャ＆録画ツール。名前の由来は BABYMETAL の名曲 **[「ギミチョコ！！」(Gimme chocolate!! Official Video)](https://www.youtube.com/watch?v=WIKqgE4BwAY)** です。

---

### 🎸 デザインのインスピレーション
**GimmeCapture!!** は、高速でエネルギッシュ、そして強烈なスタイルを目指しています。UI の配色やテーマは BABYMETAL の美学をオマージュしています。

### 主な機能
- **スマートキャプチャ**：インスタント編集ツールを備えた高性能スクリーンキャプチャ。
- **画面録画 + システム音声**：画面映像とデスクトップ音声を MP4 / MKV / GIF などで録画。
- **翻訳モード**：OCR + 翻訳ワークフローに対応。単一/複数選択、言語選択、翻訳結果オーバーレイ表示が可能。
- **最前面にピン留め**：キャプチャをフローティングウィンドウとしてピン留め。
- **動画ピンプレイヤー**：再生/一時停止、ループ、シーク、再生速度 (0.5x/1.0x/1.5x/2.0x)、ミュート切替に対応。
- **編集ツール**：キャプチャ上に直接、図形、矢印、線、テキストを描画。
- **カスタマイズ可能なキー**：「操作」タブで全てのショートカットキーを自由に設定可能。
- **個性化外観**：枠線の太さ、マスクの不透明度、テーマカラー（ゴールド、シルバー、レッド）を調整可能。
- **装飾サイズ調整**：**サイドウィング (0.5x - 3.0x)** や**コーナーアイコン (0.4x - 1.0x)** のサイズを好みに合わせて調整可能。
- **スタートアップ起動**：Windowsの起動時に自動的にアプリを開始可能。
- **リアルタイム音量メーター**：録画ツールバーで入力/出力レベルと dB 状態を表示。

### 使い方
1. 起動後、ツールバーで **キャプチャ / 録画 / 翻訳** の3モードを切り替えます。
2. キャプチャモードでは範囲選択後、注釈追加、コピー、保存、ピン留めができます。
3. 録画モードでは開始/一時停止/停止ができ、ツールバーで入力/出力音量をリアルタイム確認できます。
4. 翻訳モードでは入力/出力言語を設定し、単一または複数選択で翻訳または OCR スキャンを実行します。
5. ピン留めウィンドウは右クリックで機能メニューを開けます。動画ピンは再生、速度、音声操作に対応します。

### 翻訳モード補足
- ツールバーの翻訳アイコンから **翻訳モード** に切り替えます。
- 入力言語/出力言語を設定し、**単一選択** または **複数選択** で領域を指定します。
- **Translate All** で全選択を翻訳、**Scan All** で OCR のみ実行できます。
- 翻訳結果オーバーレイは翻訳ツールバーから表示/非表示を切り替えできます。

### 録画 / 動画ピンに関する補足
- システム音声録音は **Settings > Record** で ON/OFF できます。
- 動画ピンモードでは、音声は**デフォルトでミュート**です。
- 動画ピンモードでは **Shift + M** でミュート/ミュート解除を切り替えできます。
- 動画の再生速度変更は、音声再生速度にも反映されます。

### 📦 サードパーティコンポーネント
- **FFmpeg**: 画面録画とマルチメディア処理に使用されます。FFmpeg は [GPL/LGPL](https://ffmpeg.org/legal.html) ライセンスの下で提供されています。本アプリは、[BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds) から FFmpeg バイナリを自動的にダウンロードします。
- **NAudio**: 録画時のシステム音声ループバック取得と、リアルタイム音量モニタリングに使用します。
